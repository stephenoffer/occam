# Passwords and two-factor sign-in

Use the company password manager for every work account. Generated passwords should be at least
20 characters. Never reuse a work password anywhere else.

Two-factor sign-in is required for email, the code host and the cloud consoles. Use the
authenticator app or a hardware key; text messages aren't accepted.

If you think a password has leaked, change it straight away and tell security in #security-help.
Nobody from IT will ever ask you for your password.
