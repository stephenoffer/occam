Not safe to merge. In src/middleware/auth.js a request with no x-signature header returns `!config.requireSignature`, and src/config.js sets requireSignature only when REQUIRE_SIGNATURE is the string "true". deploy/production.env does not set it, so in production unsigned requests are accepted. Anyone who can reach the endpoint can forge webhooks by leaving the header out.
